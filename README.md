# Sistema de Alerta Temprana de Deserción Educativa

Plataforma web desarrollada en Python orientada a la gestión educativa y al seguimiento tutorial. El sistema centraliza información académica y socioeconómica para identificar tempranamente señales asociadas al riesgo de deserción mediante la integración de un modelo de Inteligencia Artificial.

## 🚀 Tecnologías Utilizadas
* **Lenguaje:** Python 3.9+
* **Frontend / Framework Web:** Streamlit
* **Base de Datos:** SQLite
* **Inteligencia Artificial:** Scikit-learn / API (Generación de predicciones de riesgo)
